# v0.2 Release Checklist

Use this checklist before tagging `v0.2.0`.

## Scope

v0.2 is a hardening release for realistic fixtures, reports, CI, and
throughput visibility. It does not add LLM synthesis, local model inference,
LogBERT, or PyPI publishing.

## Required Checks

```bash
python -m pytest -q
python -m build
python -m twine check dist/*
```

Fresh-wheel smoke:

```bash
python -m venv /tmp/logmask-wheel-test
/tmp/logmask-wheel-test/bin/python -m pip install --upgrade pip
/tmp/logmask-wheel-test/bin/python -m pip install dist/logmask_drain-*.whl
/tmp/logmask-wheel-test/bin/logmask --help
/tmp/logmask-wheel-test/bin/logmask synthesize tests/fixtures/toy/sample.txt \
  --backend rules \
  --rule-mode conservative \
  --out /tmp/masks.json
/tmp/logmask-wheel-test/bin/logmask validate-masks /tmp/masks.json \
  --logs tests/fixtures/toy/sample.txt \
  --strict
/tmp/logmask-wheel-test/bin/logmask parse tests/fixtures/toy/logs.txt \
  --masks /tmp/masks.json \
  --template-id-mode hash \
  --out /tmp/parsed.jsonl
/tmp/logmask-wheel-test/bin/logmask report /tmp/parsed.jsonl
/tmp/logmask-wheel-test/bin/logmask benchmark \
  --logs tests/fixtures/toy/logs.txt \
  --ground-truth tests/fixtures/toy/templates.csv \
  --methods drain,builtin,bundle \
  --masks /tmp/masks.json
```

Performance smoke:

```bash
logmask perf-benchmark --lines 10000 --out /tmp/logmask-perf-10k.json
```

## Release Notes Framing

Frame v0.2 as:

- CPU-only and local.
- Deterministic once the mask bundle is fixed.
- Focused on realistic-log hardening and report-guided tuning.
- Still not the DeepParse authors' fine-tuned DeepSeek artifact.
